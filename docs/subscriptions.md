# 订阅管理

## 日常使用

从文件、HTTPS 链接、二维码或已支持的节点列表导入，校验后预览并确认保存。文件名称默认去掉扩展名，可重命名。相同来源和原文重复导入沿用记录，保留选择；同名不同内容分别保存。

未连接时切换只改变当前订阅；连接中切换需确认断开并重连。停止等待最多 15 秒，超时保留原选择。各订阅独立保存节点选择；select 热切只影响新连接。

支持单项、多选和侧滑删除。删除当前订阅前先断开，删除后不自动选择另一份。删除 App 不保证移除钥匙串数据，敏感记录应在订阅页删除。

## 更新与回滚

详情页可补充来源链接、手动刷新、更新 Geo 和浏览历史。下载完成先显示差异，确认后才提交；失败保留原版本。资源变化也计入版本，不只比较 YAML 原文。

每份保留最近五个历史快照，并另保留最近一次请求成功的快照。回滚恢复完整配置、依赖与选择并生成新修订。新版本首次启动失败时最多尝试恢复一次；主动断开取消恢复。启动检查要求系统状态与扩展配置标识一致，但不代表节点或所有协议可达。

索引最后原子提交；失败清理候选。删除清理在后台串行进行，前台按有限退避重试，未清理条目不能重新选用。旧 App 不保证读取新版索引和资源快照，降级前保留可重装归档及原始配置。

## 下载与存储

- 主输入 1 MiB；其余容量见[兼容清单](compatibility.md)。
- 来源 URL 最多 8192 UTF-8 字节。使用 HTTPS、临时 URLSession、最多五次同源跳转；仅精确公共 Geo 来源允许指定 GitHub CDN 例外。
- 网络预算：无数据等待 10 秒、单次总时限 20 秒、整次导入／刷新 30 秒。CPU 预检不能强制中断，取消后丢弃迟到结果。
- 默认 Geo 使用已校验快照或内置资源；带查询参数、自定义来源和私有 providers 不被替换。显式更新失败不删除旧资源或规则。
- 原文、来源、凭据、选择与历史使用 AfterFirstUnlockThisDeviceOnly 钥匙串。未开启[可选 iCloud 同步](icloud-subscription-sync.md)时不跨设备上传。

## 二维码分享

有有效 HTTPS 来源的订阅可以分享二维码。图片在本机生成并保留静区，过长链接报错，不截断令牌。二维码包含完整来源及可能的凭据，接收者可据此访问订阅。生成和分享本身不下载配置或改变 VPN。

## 验证

`check-configuration.py`、`check-subscription-deletion.py`、`check-subscription-download.swift`、`check-subscription-qr.swift` 及 HorizonTests 中的维护、快照、二维码和导入测试。真实刷新、更新失败恢复、大历史写入及断开超时需另做设备验收。
