# 稳定性验收

既有记录包含真实出口核对、断开／重连、App 后台及主进程结束后的扩展存活。两份订阅切换、Wi-Fi／蜂窝切换、短时断网与锁屏恢复已有用户正常反馈；这些是特定版本和配置的结果，不代表全部组合通过。

## 发布前检查

| 项目 | 验收重点 |
| --- | --- |
| 生命周期 | 反复启停、连接中取消、快速操作、系统移除配置、扩展异常退出 |
| 配置事务 | 下载／预检失败保留旧版、切换超时、Keychain 失败、新版启动恢复和主动断开取消恢复 |
| 节点 | 失效节点、认证／证书错误、热切后的新旧连接路径、批测取消与迟到结果 |
| 网络 | Wi-Fi／蜂窝切换、无网后恢复、DNS 路径，以及实际配置所需 TCP／UDP／IPv4／IPv6 |
| 后台 | 锁屏、App 被挂起／终止、历史补取、系统控件和灵动岛操作 |
| 性能 | 长时间运行、扩展内存峰值、任务／FD 数量、耗电与温度趋势 |
| 同步 | 离线冲突、换账户、配额不足、待处理当前订阅和发布环境读写 |

曾出现网页可用但独立 DNS 诊断超时；两者路径不同，排查需分别记录解析器、缓存与请求结果，不因网页成功就认定无 DNS 问题。

记录测试版本、设备／网络、配置范围及实际结果，区分工具实测、用户反馈和未验证项。只保留脱敏类别、计数及时间，不记录完整出口 IP、订阅或节点凭据。构建与离线测试不替代上述真机验收。
