# 功能检查

当前范围：订阅导入／维护、节点与策略组、连接控制、测速、真实流量、诊断、可选 iCloud 同步、系统控件和两套界面。协议与参数以[兼容清单](compatibility.md)为准。

## 验收入口

- 导入：空库、取消、损坏输入、容量边界、重复、兼容诊断及预览不提前保存。
- 管理：独立选择、重命名、批量删除、刷新差异、版本冲突、失败保留与回滚。
- 连接：权限拒绝、重复点击、超时／取消、配置切换、旧响应隔离和真实系统状态。
- 观测：单测／批测取消、真实计数、采样缺失、断开归零、会话与历史隔离。
- 系统：iPad 布局、长名称／大字号、VoiceOver、后台及控件的认证边界。
- 同步：关闭默认值、上传范围、冲突、当前订阅保护及云端环境。

逐项记录结果，不从代码存在或编译成功推定通过。网络、长期运行和性能用例见[稳定性清单](stability-validation.md)，相关功能文档给出测试入口。
