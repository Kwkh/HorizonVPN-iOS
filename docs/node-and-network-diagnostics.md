# 节点与网络诊断

## 选择与隐私

节点页或设置中可切换原名／隐私显示。默认隐私，隐藏名称时只按协议与编号搜索；偏好不会把名称另存到普通日志。

未连接时保存选择供下次使用；连接中通过内核 select 接口热切。确认实际运行结果后才持久化；确认丢失时查询内核指纹，无法确定或恢复失败时请求停止。热切只影响新连接，已有 TCP／UDP 会话保持原路径。

## 规则观测

手动开启后读取活动连接的规则类型、可唯一对应的规则序号、节点／组编号及网络类型。记录有界，仅在内存保存，退出、后台或切配置时清空。重复规则、短连接、拒绝或失败请求可能无法唯一归属或被采到，不能据此承诺完整访问日志。

## DNS 与链路

DNS 页面分别执行 A／AAAA 查询、节点引导解析和固定 HTTPS 探测，显示计数、RCODE、耗时及固定错误类别。HTTPS 探测不访问输入域名；DIRECT／拒绝目标只做 DNS 检查。

查询域名在操作内存中使用并发往配置的 DNS，不写历史。返回地址及原始错误不跨进程展示。桥接没有暴露实际命中的上游、策略或缓存来源，耗时也不是某台 DNS 的纯延迟，不能证明无泄漏。

离开或停止后丢弃迟到响应；已发出的内核 DNS 查询无法强制撤回，受内核超时约束。进行中的测速、热切与诊断遵守互斥保护。

验证入口：`check-selection-core.py`、`check-network-inspection.swift`、`check-node-shortcut.swift` 及相关 HorizonTests。真实热切、旧连接保持、DNS 路径和存储失败恢复另行设备验收。
