# 首次引导

首次进入依次展示 Welcome、功能指南和首页入场；完成状态保存在本地，已有安装不因升级重复播放。父页面管理导航，子组件只管理自身呈现。

- Welcome 字标逐笔绘制，完成后继续分割线与说明，再显示 Next。标题实现为 HorizonWelcomeWordmark，时序由完成事件衔接。
- 指南通过订阅、节点和连接三个场景介绍功能，共享相机与场景时钟，保持地球自转和场景交接连续。
- 减少动态效果时简化过渡；VoiceOver、大字号、跳过、后台恢复和中途离页都有对应状态处理。
- 引导期间不提前启动网络监控或弹出网络权限；结束后才提供 VPN 设置入口。添加配置和联网检查分别处理，不把取消视为同意。
- 正常冷启动可播放首页局部入场，不重复首次指南；用户主动导航离开后不自动重播。

组件位于 `Horizon/Features/Horizon/`，呈现记录由 FirstLaunchExperience 管理。标题旧实现仅供定点回退，见[回档说明](design/welcome-title/README.md)。

验证包括相机、进度、场景交接、跳过与权限时序相关检查。最终运镜、字体与过渡体验由真机验收；设计数值见[设计规范](design/Horizon-Design-System.md)。
