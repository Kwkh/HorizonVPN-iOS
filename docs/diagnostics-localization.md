# 诊断界面语言（2026-10-04）

连接诊断主页、扩展统计、联网测试、离线验证、会话记录及确认框采用现有 AppSettings 语言选择。规则与 DNS 页补全运行结果提示的英文显示。配置名称保留用户原名，内核协议标识、域名测试目标和错误码不翻译。

DiagnosticText 只接收已脱敏的服务摘要，按固定文案与错误码映射英文；不读取原始内核错误或 NSError userInfo。未知中文文案提供英文后备提示；携带错误码时保留错误码。配置字段的逐项诊断仍在兼容性报告中查看。共享错误类型与日志存储格式保持不变，切换语言时重新格式化会话内容。

验证：模拟器英文界面检查主要分区、按钮与离线结果（133/133）；check-diagnostic-text.swift 检查固定状态、耗时、19 个内核错误码、系统错误域区分和脱敏后备。模拟器构建通过。未进行真实联网诊断或系统 VPN 权限操作。

```sh
# 已运行 scripts/check-configuration.py，具备本地 host parser 后：
python3 scripts/check-diagnostic-text.py
```
